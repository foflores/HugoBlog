# Hugo Blog

A static blog built using [Hugo](https://gohugo.io) and [Hugo-PaperMod](https://github.com/adityatelange/hugo-PaperMod).

While the main goal initially was to learn how Hugo worked, this repo served as a good foundation for exploring other tools. Over time, I added a Pulumi C# project to define the necessary infrastructure and GitHub actions to deploy both the infrastructure and the app itself.

## Website

The latest version of this project can be found [here](https://hugoblog.favianflores.com).
